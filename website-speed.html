Website speed and Core Web Vitals

Practical measurements and improvements for visitors on real devices and connections.

Practical guide · RanSan Technology · Updated November 2026

Measure before changing infrastructure

Use Chrome's Lighthouse for lab diagnostics and PageSpeed Insights / Chrome UX Report where field data is available. Field and lab results measure different conditions, so review both.

Prioritise meaningful metrics

  • Largest Contentful Paint (LCP): when the largest visible content element becomes available
  • Interaction to Next Paint (INP): how responsive the page is to interactions
  • Cumulative Layout Shift (CLS): unexpected visual movement during loading

Fix common bottlenecks

Compress and correctly size images, reserve their layout dimensions, avoid excessive third-party scripts, cache static assets responsibly, and use fewer fonts and heavy animation libraries. On content management systems, remove unused plugins and assess server response times.

Re-test realistic journeys

Test key pages on mobile, including the contact experience. Consider business impacts such as users reaching information or submitting enquiries successfully, rather than assuming any single score will guarantee higher search rankings.
